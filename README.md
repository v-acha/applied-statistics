
# Applied Statistics

A collection of applied statistical analyses examining real-world questions
through hypothesis testing, regression modeling, effect-size estimation,
and exploratory data analysis.

## Projects

| Project | Research Question | Methods | Key Finding |
|---|---|---|---|
| [Voting Difficulty Across Political Groups](voting_dfficulty_testing/README.md) | Do reported voting-difficulty scores differ between groups? | Wilcoxon rank-sum test, Welch's t-test, effect sizes | Statistical tests produced different significance results, while estimated effect sizes were small or negligible. |
| [Campaign Spending and Election Outcomes](campaign_spending_analysis/README.md) | How are campaign spending and party affiliation associated with vote totals? | Linear regression, hypothesis testing, ANOVA/model comparison | Campaign spending showed a statistically significant positive association with vote totals in the fitted models. |
| [Eldercare Time and Household Factors](elder_care_analysis/README.md) | How are earnings, employment, household composition, and work hours associated with time spent on eldercare? | Multiple linear regression, model comparison | Household characteristics, particularly the presence of children, showed stronger relationships with eldercare time than earnings in the fitted models. |

## Methods

Across these projects, analyses include:

- Hypothesis testing
- Linear and multiple regression
- Nonparametric testing
- Effect-size estimation
- Model comparison
- Exploratory data analysis
- Statistical visualization
